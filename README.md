# 💰 BancoApp

Projeto simples de aplicação bancária desenvolvido em Java, como parte dos estudos da disciplina de Programação Orientada a Objetos (POO).

## 📚 Descrição

A aplicação simula um sistema de gerenciamento bancário no terminal. O usuário pode criar uma conta, acessar com CPF, consultar saldo, realizar depósitos, saques e encerrar a sessão. O projeto utiliza princípios básicos de POO como classes, objetos, métodos e encapsulamento.

## 🚀 Funcionalidades

- Criar conta bancária
- Login com nome, sobrenome e CPF
- Consultar saldo
- Realizar depósitos
- Realizar saques
- Encerrar sessão com mensagem personalizada

## 🛠️ Tecnologias utilizadas

- Java 17
- NetBeans IDE
- Maven (caso aplicável)
